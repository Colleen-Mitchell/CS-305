# CS-305
SNHU Software Security Course


Artemis Financial is a financial trading company who preforms both domestic and international transactions. They are looking to create a client user interface to enable customer controlled account transactions and viewing.

In order to meet industry, legal, and consumer trust standards, Artemis financial needs to develop a secure application. When vulnerabilities were found, they were examined for relevance, severity, and potential mitigation plans were advised and implemented. 

Coding securely creates a more secure end product and reduces the expense of adding security to meet regulatory guidelines in post production. In the future, I intend to use best practices that include safe untrusted data and input handling and dependency management. 

Code was refactored to enable https and include a checksum, secure hashing, and proper input sanitization and media type.

Code was checked after refactoring by rerunning static tests to check for any vulnerable dependent libraries with the OWADP dependency check.

The OWAS dependency tool, windows PowerShell key tool, maven repository and NVD database will all be useful in future projects. 

This project shows secure key generation and keystore management, certificate generation, HTTPS, and hashing
